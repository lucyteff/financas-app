Historia 1: 
Como usuário, quero visualizar cotações atualizadas de moedas estrangeiras em um layout otimizado para mobile, com opção de atualização manual e automática.

Critérios de aceitação:
- Dados devem vir da AwesomeAPI
- Exibir USD, EUR, ARS e BRL em cards responsivos
- Atualização automática a cada 5 minutos
- Gestos touch (puxar para atualizar) em dispositivos móveis
- Indicador visual de carregamento durante atualizações
- Layout que se adapta a diferentes tamanhos de tela

História 2:
Como usuário, quero registrar meus gastos e poupanças em um formulário simplificado para mobile, visualizando um gráfico comparativo com minhas metas.

Critérios de aceitação:
- Formulário otimizado para touch com campos grandes
- Validação em tempo real dos campos
- Gráfico de barras responsivo com três categorias
- Toque longo em valores no gráfico para detalhes (mobile)
- Hover em valores para detalhes (desktop)
- Cards reutilizáveis para exibir resumos
- Transições suaves entre estados
